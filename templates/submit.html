提交研究文章

貼上文章或你的筆記後按「送出」，會幫你開一個 GitHub Issue（這個網站本身是純靜態頁面， 沒有後端伺服器，所以用 你自己 repo 的 GitHub Issue 當唯一的「上傳信箱」）。
流程：1. 這裡填好內容 → 2. 開新分頁後確認並按 GitHub 上的「Submit new issue」→ 3. 系統會抓到這篇提交，用 LLM 分析、嚴格驗證內容真偽，只有驗證通過的部分才會 回寫進題材知識庫 → 4. 結果會留言在你的 Issue 裡，也會出現在 研究筆記 頁面。
0 字

內容太長（超過約 5,000 字）時，GitHub 的網址長度可能塞不下， 建議先貼重點摘要，或分成幾次提交。系統只會把「驗證通過」的內容回寫進真實報告， 未經驗證或跟既有資料衝突的部分只會留在研究筆記裡不會影響正式資料。
